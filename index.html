Why KingCobra

  
Easy like a script. Native like C.

  
One language from a quick REPL experiment to a bootable kernel — with the sharp edges labelled.

  

    
01 · syntax
Pleasant to write
let/var, f-strings, slicing, destructuring, match, try/catch, and Python-style help().

    
02 · speed
Closure JIT
Hot int functions compile to x86-64 machine code at run time — a measured ~108× over the interpreter on recursive fib. Optional, never required.

    
03 · memory
Explicit, checked
No GC. Use-after-free and double free are errors, defer survives unwinding, and --leaks finds what you forgot.

    
04 · ffi
Real native FFI
extern fn into any shared library, native .o import, and rhex + unsafe for raw machine code.

    
05 · types
Static type checker
Runs before your program: annotations, signatures, returns, struct fields. Errors show source excerpts and “did you mean”.

    
06 · portable
Runs everywhere
Linux and Windows on x86-64, ARM64, ARMhf and RISC-V. One Makefile, no third-party build dependencies.

Before you start
Build it, run it, meet the REPL


You need a C11 compiler and make (on Windows, MSYS2 / MinGW-w64). Then:


terminal
git clone https://github.com/DivyanshuSinha136/kingcobra.git
cd kingcobra
make                      # builds ./kingcobra
./kingcobra version


Create a file called hello.kc (the .kc extension is how KingCobra files are named) and run it with ./kingcobra run hello.kc. We'll write it in the next lesson.


Want it on your PATH? Run the tests, then install:
terminal
make test
sudo make install


The REPL is a scratchpad: type code, see the result immediately. Start it with ./kingcobra repl. The special name _ holds the last result.


terminal
>>> let x = 10
>>> x * 3
30
>>> _ + 1
31


Handy commands kingcobra check file.kc checks a program without running it · kingcobra -e 'print(6 * 7)' runs a one-liner · kingcobra help topics opens the built-in help.




Lesson 1
Your first program


Every program has a main function. KingCobra runs the top-level statements, then calls main().


hello.kc
// my first program
fn main() {
    print("Hello, KingCobra!");
    print("2 + 3 =", 2 + 3);
}
output
Hello, KingCobra!
2 + 3 = 5


  • fn declares a function.
  • print(...) writes its arguments separated by spaces.
  • Statements end with ;. Comments start with //.


Lesson 2
Values and variables


Use let for a value you won't change and var for one you will. Types are optional — KingCobra infers them — but you can write them down and the type checker will hold you to it.


program.kc
fn main() {
    let name = "Ada";
    var score = 10;
    score = score + 5;
    let pi: float = 3.14159;
    let ok: bool = true;
    let nothing = null;
    print(name, score, pi, ok, nothing);
    print(10 / 3, 10 % 3, 7 / 2.0);
    print(f"{name} has {score} points");
}
output
Ada 15 3.14159 true null
3.33333 1 3.5
Ada has 15 points

Watch out ** is not "to the power of" — in KingCobra it dereferences a pointer. Multiply, or write a small function, to raise to a power.


Lesson 3
Decisions and loops


Conditions go in parentheses and bodies in braces. for (i in 0..5) counts 0, 1, 2, 3, 4 — the end is not included.


program.kc
fn main() {
    let age = 17;
    if (age >= 18) {
        print("adult");
    } else if (age >= 13) {
        print("teenager");
    } else {
        print("child");
    }

    for (i in 0..5) { print("i =", i); }

    var n = 3;
    while (n > 0) { print("countdown", n); n = n - 1; }

    let label = age >= 18 ? "can vote" : "too young";
    print(label);
    print(match (age) { 17 => "seventeen", _ => "other" });
}
output
teenager
i = 0
i = 1
i = 2
i = 3
i = 4
countdown 3
countdown 2
countdown 1
too young
seventeen


cond ? a : b picks one of two values, and match compares a value against patterns (_ matches anything). Use break and continue inside loops.

Lesson 4
Functions


Functions take typed parameters and say what they return with ->. Parameters can have defaults, and functions are values you can store in variables.


program.kc
fn square(x: int) -> int {
    return x * x;
}

fn greet(name: string, greeting: string = "Hello") -> string {
    return f"{greeting}, {name}!";
}

fn main() {
    print(square(7));
    print(greet("Ada"));
    print(greet("Ada", "Hi"));

    let double = fn(x: int) -> int { return x * 2; };
    print(double(21));
}
output
49
Hello, Ada!
Hi, Ada!
42
Try it · The bigger one
Write bigger(a, b) that returns the larger of two ints.
Show a solution
program.kc
fn bigger(a: int, b: int) -> int {
    if (a > b) { return a; }
    return b;
}
fn main() { print(bigger(3, 9), bigger(12, 4)); }
output
9 12


Lesson 5
Arrays and strings


Arrays grow with push, slice with a[1..3] (end excluded), and come with map and filter. Strings have methods too.


program.kc
fn main() {
    let nums = [5, 3, 8, 1, 9];
    nums.push(4);
    print(nums, len(nums), nums[0], nums[1..3]);
    print(nums.map(fn(x) -> int { return x * x; }));
    print(nums.filter(fn(x) -> bool { return x > 4; }));

    for (n in nums) { print(n); }

    let [first, ...rest] = nums;   // destructuring
    print(first, rest);
    print(8 in nums);

    let s = "hello world";
    print(s.upper(), s.split(" "), len(s));
    print(["a", "b", "c"].join("-"));
}

Try it · Sum of even squares
From [1, 2, 3, 4, 5, 6], keep the even numbers and add up their squares.
Show a solution
program.kc
fn main() {
    let nums = [1, 2, 3, 4, 5, 6];
    let evens = nums.filter(fn(x) -> bool { return x % 2 == 0; });
    var total = 0;
    for (n in evens) { total = total + n * n; }
    print(evens, total);
}
output
[2, 4, 6] 56


Lesson 6
Structs, methods and enums


A struct groups named fields. impl attaches methods, and self is the value the method is called on. An enum names a set of constants.


program.kc
struct Point { x: int, y: int }

impl Point {
    fn len2(self) -> int { return self.x * self.x + self.y * self.y; }
}

enum Color { Red, Green = 10, Blue }

fn main() {
    let p = Point { x: 3, y: 4 };
    print(p.x, p.y, p.len2());
    p.x = 6;
    print(p.len2());
    print(Color.Green, Color.Blue);
}
output
3 4 25
52
10 11
Structs are reference types: if you copy one into another variable, both names point at the same fields.


Lesson 7
Handling errors


Use throw error("…") to signal a problem and try/catch to handle it. The caught value has a message.


program.kc
fn parse_age(text: string) -> int {
    let n = int(text);
    if (n < 0) { throw error("age cannot be negative"); }
    return n;
}

fn main() {
    for (text in ["30", "-4"]) {
        try {
            print("age", parse_age(text));
        } catch (e) {
            print("rejected:", e.message);
        }
    }
}
output
age 30
rejected: age cannot be negative


Mistakes in your own code come with a location and a source excerpt, like l2.kc:9:39: error: … followed by the offending line and a caret. Read them from the top — the first one is usually the real problem.


Lesson 8
Memory, the KingCobra way


KingCobra has no garbage collector. Memory you allocate with alloc is yours to free. defer schedules a statement to run when the function ends — even if an error happens — so you can't forget.


program.kc
fn main() {
    let buf = alloc(16);
    defer free(buf);
    print("allocated, will be freed automatically");
}
output
allocated, will be freed automatically


Using memory after freeing it, or freeing it twice, is a clear runtime error — never silent corruption. And if you do forget, run with --leaks:


leak.kc
fn main() {
    let buf = alloc(16);
    print("oops, forgot to free");
}
output
oops, forgot to free
kingcobra: memory report
  leaked blocks (allocated, never freed):
          16 bytes  alloc()       at leak.kc:2:15
  total: 1 block(s), 16 byte(s)
terminal
kingcobra --leaks run leak.kc


Lesson 9
Using the standard library


Pull in a module with import std.<name>;. KingCobra ships 21, with nothing to install. Here: parse JSON and read/write a file.


program.kc
import std.json;
import std.io;

fn main() {
    let doc = json.parse("{\"name\": \"Ada\", \"langs\": [\"kc\", \"c\"]}");
    print(doc["name"], doc["langs"]);

    io.write_file("hello.txt", "hi from KingCobra\n");
    print(io.read_file("hello.txt"));
}
output
Ada [kc, c]
hi from KingCobra


Run kingcobra modules to list them all, and see the docs folder for each module's reference. You can also split your own code across files with import "other.kc";.


Lesson 10
Testing your code


Any function whose name starts with test_ is a test. assert fails the test when its condition is false.


math.kc
fn add(a: int, b: int) -> int { return a + b; }

fn test_add() {
    assert(add(2, 3) == 5);
}

fn test_negative() {
    assert(add(-1, 1) == 0);
}
output
terminal
$ kingcobra test math.kc
math.kc
  ok   test_add
  ok   test_negative

2 passed, 0 failed  (0 ms)


Start a fresh project with kingcobra new myapp — it creates main.kc, a test file, a README and a .gitignore.

NASM-style x86 assembler for 16/32/64-bit code with ELF, bin and HEX output. KASM docs →

Memory model

    
No garbage collector. No silent corruption.

    
You decide when memory is freed — the runtime makes mistakes loud instead of quiet.

    
    
      
  • free works on every heap value.
    • 
      
  • Use-after-free and double free are runtime errors.
    • 
      
  • defer runs even while an error unwinds.
    • 
      
  • Bounds- and lifetime-checked pointers and buffers.
