Why KingCobra

  
Easy like a script. Native like C.

  
One language from a quick REPL experiment to a bootable kernel — with the sharp edges labelled.

  

    
01 · syntax
Pleasant to write
let/var, f-strings, slicing, destructuring, match, try/catch, and Python-style help().

    
02 · speed
Closure JIT
Hot int functions compile to x86-64 machine code at run time — a measured ~108× over the interpreter on recursive fib. Optional, never required.

    
03 · memory
Explicit, checked
No GC. Use-after-free and double free are errors, defer survives unwinding, and --leaks finds what you forgot.

    
04 · ffi
Real native FFI
extern fn into any shared library, native .o import, and rhex + unsafe for raw machine code.

    
05 · types
Static type checker
Runs before your program: annotations, signatures, returns, struct fields. Errors show source excerpts and “did you mean”.

    
06 · portable
Runs everywhere
Linux and Windows on x86-64, ARM64, ARMhf and RISC-V. One Makefile, no third-party build dependencies.

Lesson 1
Your first program


Every program has a main function. KingCobra runs the top-level statements, then calls main().


hello.kc
// my first program
fn main() {
    print("Hello, KingCobra!");
    print("2 + 3 =", 2 + 3);
}
output
Hello, KingCobra!
2 + 3 = 5


  • fn declares a function.
  • print(...) writes its arguments separated by spaces.
  • Statements end with ;. Comments start with //.


Lesson 2
Values and variables


Use let for a value you won't change and var for one you will. Types are optional — KingCobra infers them — but you can write them down and the type checker will hold you to it.

Lesson 3

Lesson 6
Structs, methods and enums


A struct groups named fields. impl attaches methods, and self is the value the method is called on. An enum names a set of constants.


program.kc
struct Point { x: int, y: int }

impl Point {
    fn len2(self) -> int { return self.x * self.x + self.y * self.y; }
}

enum Color { Red, Green = 10, Blue }

fn main() {
    let p = Point { x: 3, y: 4 };
    print(p.x, p.y, p.len2());
    p.x = 6;
    print(p.len2());
    print(Color.Green, Color.Blue);
}
output
3 4 25
52
10 11
Structs are reference types: if you copy one into another variable, both names point at the same fields.


Lesson 7
Handling errors


Use throw error("…") to signal a problem and try/catch to handle it. The caught value has a message.


program.kc
fn parse_age(text: string) -> int {
    let n = int(text);
    if (n < 0) { throw error("age cannot be negative"); }
    return n;
}

fn main() {
    for (text in ["30", "-4"]) {
        try {
            print("age", parse_age(text));
        } catch (e) {
            print("rejected:", e.message);
        }
    }
}
output
age 30
rejected: age cannot be negative


Mistakes in your own code come with a location and a source excerpt, like l2.kc:9:39: error: … followed by the offending line and a caret. Read them from the top — the first one is usually the real problem.


Lesson 8
Memory, the KingCobra way


KingCobra has no garbage collector. Memory you allocate with alloc is yours to free. defer schedules a statement to run when the function ends — even if an error happens — so you can't forget.


program.kc
fn main() {
    let buf = alloc(16);
    defer free(buf);
    print("allocated, will be freed automatically");
}
output
allocated, will be freed automatically


Using memory after freeing it, or freeing it twice, is a clear runtime error — never silent corruption. And if you do forget, run with --leaks:


leak.kc
fn main() {
    let buf = alloc(16);
    print("oops, forgot to free");
}
output

  total: 1 block(s), 16 byte(s)

Language reference · structs and FFI
Structs you can lay out, C you can call.
KingCobra structs work two ways. As ordinary values they are named, type-checked records. When every field has a machine type they also get a real C layout, so you can place them in raw memory, read them through pointers and hand that memory to native code. The FFI binds straight to shared libraries with extern, or opens a compiled .o or .so with a plain import. No header files, no wrapper generator.


structpacked structunionextern fnimport "lib.o"unsafe




11machine types: u8 i8 u16 i16 u32 i32 u64 i64 f32 f64 bool


6maximum parameters of an extern function


2argument kinds per call: all int-like or all float


0bounds checks inside C. KingCobra checks its side, you vouch for the rest.




01 · values
Reference semantics
Copying a struct copies a reference, as with arrays. Mutating through any name is visible through every other name.
02 · layout
C layout on demand
sizeof, alignof and offsetof give the real offsets. packed struct removes padding. union overlays fields.
03 · safety
Checked until C takes over
Pointers into KingCobra memory are bounds and liveness checked. Handing an address to native code needs an explicit unsafe block.





01 · Structs
Declare, construct, mutate


Declare a struct with named, typed fields, then build one with a literal. Fields are read and written with .. Because structs are reference types, passing one to a function lets the function change it.


structs.kc
struct Point {
    x: int,
    y: int,
}

fn dist_sq(p: Point) -> int {
    return p.x * p.x + p.y * p.y;
}

fn translate(p: Point, dx: int, dy: int) {
    p.x += dx;
    p.y += dy;
}

fn main() {
    let a = Point { x: 3, y: 4 };
    print("a =", a);
    print("dist_sq(a) =", dist_sq(a));

    translate(a, 1, 1);      // structs are references, so this mutates `a`
    print("after translate, a =", a);

    let b = a;               // same reference
    b.x = 100;
    print("a.x after mutating through b:", a.x);
}
output
a = Point { x: 3, y: 4 }
dist_sq(a) = 25
after translate, a = Point { x: 4, y: 5 }
a.x after mutating through b: 100


The literal is validated against the declaration

CopyingUse a literal to make a real copy: Point { x: a.x, y: a.y }. To free a struct early, call free(p). It works on structs, arrays, strings and buffers, and later use is a catchable use-after-free error.



02 · Methods & checks
impl, enums, and what the type checker sees


impl attaches functions to a struct. A function whose first parameter is self is an instance method. Any other function is called on the type, as a constructor or helper.


impl.kc
struct Point { x: int, y: int }
impl Point {
    fn len2(self) -> int { return self.x * self.x + self.y * self.y; }
    fn origin() -> Point { return Point { x: 0, y: 0 }; }
}

let p = Point { x: 3, y: 4 };
print(p, p.len2(), Point.origin());
output
Point { x: 3, y: 4 } 25 Point { x: 0, y: 0 }


TopicRule


Method lookupx.name(...) tries a struct field first, then a user impl method, then a built-in method.


Static checkingThe type checker validates struct field types in literals and assignments, call argument types, and return types. It is permissive by design: when a type is unknown it treats it as any and skips, so valid programs are not rejected. Skip it with --no-typecheck.


Aliasestype Score = int; and typedef int myint; are the same thing, resolved while parsing. Declare them before use.


Enumsenum Color { Red, Green = 5, Blue } gives int constants (Color.Blue == 6), usable in match.





03 · Machine layout
sizeof, offsetof, packed structs and unions


A struct whose fields are all machine types has a C layout. That is natural alignment and trailing padding, the same as a C compiler on the platform would produce. Fields may be scalars, pointers (including to the struct itself), other structs by value, or fixed arrays such as u8[4] and Pt[3].


layout.kc
struct Header { magic: u32, kind: u8, len: u16, id: u64 }
packed struct Wire { magic: u32, kind: u8, len: u16, id: u64 }
struct Pt { x: i32, y: i32 }
struct Poly { tag: u8[4], pts: Pt[3] }
union Bits { i: u32, f: f32 }

print("sizeof Header", sizeof(Header), "offsetof len", offsetof(Header, len), "id", offsetof(Header, id));
print("Wire", sizeof(Wire), offsetof(Wire, id));
print("Poly", sizeof(Poly), offsetof(Poly, pts), "Bits", sizeof(Bits));
output
sizeof Header 16 offsetof len 6 id 8
Wire 15 7
Poly 28 4 Bits 4

05 · extern FFI
Declare a native function, then just call it


extern fn binds a real C symbol from a shared library at load time. The symbol must have the exact name you declare. After that it is called like any KingCobra function.


std_ffi.kc
extern fn sqrt(x: float) -> float from "libm.so.6";
extern fn pow(a: float, b: float) -> float from "libm.so.6";
extern fn labs(x: int) -> int from "libc.so.6";
extern fn strlen(s: string) -> int from "libc.so.6";

fn main() {
    print("sqrt(2) via extern libm:", sqrt(2.0));
    print("pow", pow(2.0, 10.0), "labs", labs(-42));
    print("strlen", strlen("abc"));
}
output
sqrt(2) via extern libm: 1.41421
pow 1024 labs 42
strlen 3


RuleDetail


Syntaxextern fn symbol(p1: t1, p2: t2) -> ret from "libname.so";


Typesint-like (int, bool, sized integers, pointers) or float/double. A return type of void and of *T (pointer) are supported.


ArityAt most 6 parameters. The call is checked against the declaration, so a wrong argument count is a compile-time error.


Argument kindsAll parameters must be the same kind, all int-like or all float. Mixed signatures such as (float, int) are rejected, as libffi is not used.


Library lookupLoaded when the program starts, so a missing library or symbol is reported immediately with the system loader's message.


WindowsThe same source runs unchanged. Names like libm.so.6 and libc.so.6 are mapped to the C runtime DLLs (ucrtbase.dll or msvcrt.dll), and calls use the Windows x64 calling convention.


StringsA parameter declared string accepts a string, as in strlen("abc") above. Treat it as read-only. For bytes C will write to, use a pointer you control (see the Pointers tab).


comptimeAny extern or native-import call is refused inside comptime, because it can have side effects.

07 · Pointers & unsafe
Handing memory to C, and taking it back


C does no bounds checking, so passing a pointer or buffer to native code requires an unsafe { } block. A pointer returned from an extern fn declared -> *T is raw: dereferencing it also needs unsafe.

09 · Limits & errors
What the FFI does not do


TopicNote


Mixed signaturesInt and float parameters cannot be combined in one extern. Split the call in a C shim that takes all-int or all-float arguments.


Parameter countMaximum 6 per extern function.


CallbacksThere is no way to pass a KingCobra function to C as a function pointer.


Structs by valueNot passed across the FFI. Pass a pointer to a C-layout struct in memory.


32-bit hostsOn armhf and other 32-bit targets, integer arguments and results are 32-bit words. Use a double or an out-parameter for 64-bit values.


Safety boundaryEverything on the KingCobra side is checked. Inside the C function nothing is, so a bad pointer or length handed to C can still corrupt memory.


JITFunctions that use pointer operators run in the interpreter. The JIT covers only its integer-arithmetic shape.


Not here yetBit-fields, volatile, function pointers, and dynamic (T[]) fields in C-layout structs.

01 · Quick start
Train a network in six lines


XOR is not linearly separable, so a single layer cannot solve it. A small multilayer perceptron can. This is the first program in examples/std_nn.kc, run unmodified.

import std.nn;

fn main() {
    nn.seed(42);                                   // reproducible run
    let X = [[0, 0], [0, 1], [1, 0], [1, 1]];
    let Y = [[0], [1], [1], [0]];
    let net = nn.mlp([2, 8, 1], "activation", "tanh", "out_activation", "sigmoid");

          " final loss:", h.loss[h.epochs - 1],

}

02 · Conventions
Six rules that apply everywhere


TopicRule
Tensorsn-dimensional (≤ 6) arrays of 64-bit floats, row-major. Wherever a tensor is expected you may pass a tensor handle, a number, or a rectangular nested array. Shapes are batch-first: [N, features], [N, C, H, W], [N, T, features].
OptionsTrailing name/value pairs: nn.dense(4, 8, "init", "he", "bias", false). An unknown option is an error that lists the valid ones. A single struct whose fields are the options is accepted too.
ResultsMulti-field results are structs (h.loss, r.max_rel_error). Ranked results are arrays of [item, score].
Predictionspredict, predict_class and to_array return nested arrays. forward and the math functions return tensor handles. print shows a tensor's shape and values.
RandomnessInitialisers, dropout, shuffling and splits all draw from one generator. nn.seed(n) makes a run reproducible.
Training vs inferencefit trains. predict / evaluate run in inference mode (dropout off, batch-norm uses running statistics). nn.forward(m, x) defaults to training mode — pass false as the third argument for inference.


MemoryThe interpreter has no garbage collector. In a manual loop call nn.free(t) on per-step tensors (the outputs of forward). Models, losses and optimizers live until the program ends. Tensor and file handles use their own free / close; the core free() does not apply to them.


ErrorsMistakes are ordinary positioned errors with a specific message, for example nn.einsum: subscript 'j' has inconsistent sizes (3 vs 4). A NaN/∞ loss during fit stops training with the epoch number and a suggested fix.

Accuracy & limitsAll maths is float64. The Jacobi eigen/SVD solvers have high relative accuracy and always converge, but cost O(n³) per sweep — fine up to a few hundred rows or columns, not a LAPACK replacement for thousands. A manual training loop


Use this when you need full control — custom batching, reinforcement learning, multi-loss training. train_step(model, loss, opt, x, y) does all five steps in one call and returns the loss.

let m    = nn.sequential([nn.dense(2, 8), nn.relu(), nn.dense(8, 1)]);
let loss = nn.loss("mse");
let opt  = nn.adam(m, 0.02);

let i = 0;
while (i < 200) {
    let pred = nn.forward(m, Xr);                 // training mode by default
    let l    = nn.loss_value(loss, pred, Yr);     // a plain float
    nn.zero_grad(m);
    nn.backward(m, loss);
    nn.clip_grad_norm(m, 5.0);
    nn.step(opt);
    nn.free(pred);                                // free per-step temporaries
    i = i + 1;
}

The KCNN file format


  • Layout. KCNN magic, format version, a layer tree (type, hyper-parameters, name, parameter tensors, frozen flags), then a CRC-32 trailer.
  • Exact. Little-endian 64-bit floats, so a reloaded model reproduces predictions bit-for-bit.
  • Atomic. Files are written to a temp file and renamed, so a crash never leaves a half-written model.
  • Defensive. The loader never trusts a size field. Truncated, bit-flipped or hand-edited files produce a clear error such as file is truncated, checksum mismatch or parameter shape does not match the layer definition.
  • Not stored. Optimizer state.

11 · Performance & limits
What to expect, honestly


Single-threaded CPU, float64. Measured training throughput on one core:




~6k / s784-256-128-10 MLP


~3.5k / ssmall 28×28 CNN (8/16 filters)


~1.3k / sLSTM, 16→64, 30 steps


~1k / sd=64 transformer block, T=32


  • Tensors have at most 6 dimensions; attention is full (O(T²)).
  • Not provided: cross-attention, grouped convolution, bidirectional RNN wrappers, complex numbers / FFT, non-symmetric eigenproblems.
  • padding_idx embedding rows receive no gradient by design; gradcheck skips them.
  • The learned model is fully portable: the KCNN file is little-endian float64 on every platform.

04 · Pronunciation
From dictionary to letter-to-sound rules, and how to override it


For each word the engine tries these in order. tts.explain(word) reports which path won in its source field: lexicon, dictionary, homograph, morphology, compound, acronym or rules.


StepWhat it does


1. Homographsread, record, present, object, live, lead, wind, tear, bass, bow, minute, used to and more, chosen from the neighbouring words


2. Lexiconsyour lexicon first, then a built-in dictionary of about 1,200 function words, numbers, names and irregular spellings


3. Small wordsthe before vowels, possessives (tiger's), contractions (don't)


4. Morphologyplurals with correct voicing (dogs /z/, cats /s/, boxes /ɪz/), -ed, -ing, -er, -ly, -ness, -less, -able, prefixes like un- re- dis-, on any stem already known, so one add_word covers every inflection


5. Compoundskeyboard is key + board


6. Acronymsshort or vowel-less ALL-CAPS words are spelled letter by letter


7. Rulesabout 330 context-sensitive rules for silent letters, tion, soft c and g, ough, magic-e and more, then stress assignment and vowel reduction

05 · Styles & tags
Say it sadly, whisper it, laugh in the middle


Put a tag in square brackets anywhere in the text. A style tag changes how everything after it is spoken until the next style tag. A sound event tag produces a non-verbal sound right there. Case does not matter, and adverbs and typos are understood: [Happily], [wisper] and [sarcasticaly] all work. Brackets that are not tags ([1]) stay ordinary text.

Options: bars 1 to 128, bpm, key, seed (same seed, same result), intensity 0 to 1, swing, scale=phrygian. produce and stems also take master, sidechain (kick ducking depth), rate, tail and humanize. Each role is its own track, so you can mute, solo or re-balance:

The generated arrangements are original, rule-based patterns, a starting point to edit and not a copy of any recording. groove_styles() lists the four names.
